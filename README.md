# 🎨 LMS Paint — простое приложение для рисования (сделано на Python + PyQt6)

Это обычное, понятное приложение для рисования. 
Ты можешь рисовать, стирать, менять цвет, вставлять картинки, отменять ошибки и даже менять размер холста. Всё как в Paint, только ты это запускаешь сам.

---

## 📌 Что можно делать:
- ✏️ Рисовать мышкой
- 🧽 Использовать ластик
- 🎨 Выбирать цвет
- 💾 Сохранять рисунки
- 🖼️ Вставлять изображения
- 📏 Менять размер холста
- ↩️ Отменять и возвращать действия (Undo / Redo)
- 🔧 Настраивать толщину кисти

---

## 🧠 Что тебе нужно, чтобы запустить это:

### 1. Установи Python (если у тебя его нет)
[Скачай Python с официального сайта](https://www.python.org/downloads/)  
Когда будешь устанавливать, **обязательно поставь галочку "Add Python to PATH"**

### 2. Установи библиотеку PyQt6
Открой терминал (или командную строку) и напиши:

```bash
pip install PyQt6
