LMS Paint — простое приложение для рисования (сделано на Python + PyQt6)

Это обычное, понятное приложение для рисования. 
Ты можешь рисовать, стирать, менять цвет, вставлять картинки, отменять ошибки и даже менять размер холста. Всё как в Paint, только ты это запускаешь сам.

---

Что можно делать:
- Рисовать мышкой
- Использовать ластик
- Выбирать цвет
- Сохранять рисунки
- Вставлять изображения
- Менять размер холста
- Отменять и возвращать действия (Undo / Redo)
- Настраивать толщину кисти

---

Что тебе нужно, чтобы запустить это:

1. Установи Python (если у тебя его нет)
Скачай Python с официального сайта:
https://www.python.org/downloads/
Когда будешь устанавливать, ОБЯЗАТЕЛЬНО поставь галочку "Add Python to PATH"

2. Установи библиотеку PyQt6
Открой терминал (или командную строку) и напиши:

pip install PyQt6

Кто обожает хаос
# Раздел GOOFY TOOLS:
// Случайная ерунда на холсте
Нажимаешь кнопку — и на холст сыпется рандомный бардак:
спирали, лица котов, ASCII-арт или 17 одинаковых уток.

// Кнопка "Сюрприз"
Тыкаешь, не зная, что произойдёт.
Иногда появляется радуга. Иногда всё становится зелёным. Иногда ты получаешь "сертификат художника" и ничто не меняется.

// Мем-генератор
Рандомная надпись типа "Когда ты рисуешь в PyQt6, но забываешь сохранить"
и автоматическое наложение на холст с Comic Sans.
Это гениально и глупо — как ты.

// Замедленное рисование
Режим, в котором линия рисуется с задержкой, как будто она страдает от прокрастинации. Очень медитативно и бесит одновременно.

// Звуки во время рисования
Каждое движение кисти издаёт странный звук:
бзз, мяу, шлёп, boing, или голос, шепчущий "ты молодец".

// AI-подсказки, которые не помогают
# Возможно не будет
На экране появляется текст:

"Попробуй использовать фиолетовый. Просто потому что."
Или:
"Ты рисуешь так, будто у тебя два курсора. В хорошем смысле."

// Почему мы это делаем?
Потому что не всё должно быть "эффективно" и "оптимально".
Иногда ты просто хочешь нарисовать квадрат, который улыбается.
Иногда — сохранить холст с надписью "я пытался".
Иногда — ты устаёшь быть взрослым.
